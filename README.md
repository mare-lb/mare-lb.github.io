# Portfolio

Persönliches Portfolio im Bereich Softwareentwicklung und Webentwicklung.

Die Webseite wurde entwickelt, um meinen fachlichen Hintergrund, meine technischen Kenntnisse sowie ausgewählte Studien- und Eigenprojekte zu präsentieren.

## Technologien

- HTML5
- CSS3
- JavaScript
- JSON
- Git & GitHub Pages

## Funktionen

- Responsive Webdesign
- Dark Mode
- Dynamische Projektübersicht aus JSON
- Dynamische Projektdetailseiten
- Tastaturbedienung und `prefers-reduced-motion`
